# Blink — 설계 문서

- **작성일**: 2026-08-03
- **상태**: 승인됨 (브레인스토밍 완료)
- **임시 코드네임**: Blink (변경 가능 — 프로젝트 폴더 / 번들 ID만 갱신하면 됨)

---

## 1. 개요

Lookaway 스타일의 macOS 눈 휴식 리마인더 앱. 주기적으로 화면에서 눈을 떼도록(20-20-20 규칙) 알려주고, 브레이크 시점에 오버레이나 알림으로 개입한다. 순수 로컬, 계정·클라우드 없음.

### 목적 / 범위
- **개인용 도구**로 시작, **배포는 나중에** 열어둠 (완성 기준 = "매일 쓸 만함")
- **macOS 전용** 네이티브. Windows는 나중에 별도 프로젝트로 확장 (지금은 YAGNI)
- **iOS/iPadOS 호환 아님** — 메뉴바·타 앱 위 오버레이·백그라운드 실시간 타이머가 iOS 샌드박스에서 성립 안 함. 원한다면 "예약 로컬 알림" 기반 별도 앱으로 접근 (나중 얘기)

---

## 2. 아키텍처

UI 없는 `BreakEngine`(순수 Swift: 로직·타이머·상태)를 중심에 두고, macOS UI 레이어가 감싸는 구조. 엔진은 단독 테스트 가능하고, Windows 확장 시 설계를 재사용한다.

```
BreakEngine (순수 로직)        ←→   UI 레이어 (SwiftUI / AppKit)
  - Scheduler (2단계 주기)             - MenuBarController (MenuBarExtra)
  - 브레이크 상태머신                   - SettingsView (SwiftUI)
  - 스마트 일시정지 판정 수신            - OverlayWindow (NSPanel)
  - 오늘 통계 집계                      - 알림 (UNUserNotification)
                                       - PauseMonitor (idle / 전체화면 감지)
                                       - LaunchAtLogin (SMAppService)
```

**의존 방향**: UI 레이어 → BreakEngine (단방향). 엔진은 UI를 모른다. 상태 변화는 엔진이 publish, UI가 구독.

## 3. 컴포넌트

| 컴포넌트 | 역할 | 비고 |
|---|---|---|
| **BreakEngine** | 현재 상태(작업중/브레이크중/일시정지), 다음 브레이크까지 남은 시간, 스킵·미루기 처리 | 순수 Swift, UI 의존 없음 |
| **Scheduler** | 2단계 주기 관리 (짧은 눈 쉬기 20분/20초 + 긴 브레이크 60분/5분). N개 커스텀 타이머로 확장 가능한 **배열 구조**로 설계 | 확장 포인트 |
| **PauseMonitor** | 유휴 감지(`CGEventSource` idle time) + 전체화면 앱 감지. 조건 충족 시 엔진에 "멈춰/미뤄" 신호 | macOS 의존 |
| **MenuBarController** | `MenuBarExtra`. 남은 시간, 오늘 요약(브레이크 N회·스킵 N회), 지금 쉬기 / 일시정지 토글 | |
| **OverlayWindow** | `NSPanel` 전체화면 (모든 스페이스, 항상 위). 카운트다운 + 스킵/미루기 버튼. **모니터마다 하나씩** | |
| **SettingsView** | SwiftUI 설정창. 주기, 오버레이 vs 알림 선택(종류별), 자동실행 토글 | |
| **StatsStore** | 오늘 요약을 `~/Library/Application Support/Blink/stats.json`에 저장. 날짜 바뀌면 리셋 | 순수 로직 |
| **LaunchAtLogin** | `SMAppService`로 로그인 시 자동 실행 | |

## 4. 브레이크 동작 규칙

- **개입 방식**: 오버레이 + 알림 **둘 다 지원**, 브레이크 종류별로 선택 (예: 짧은 건 알림, 긴 건 오버레이). 설정으로 조절
- **스킵(Skip)**: 이번 브레이크 취소, 다음 주기로. 통계 스킵 +1
- **미루기(Postpone)**: 지금 브레이크를 N분 뒤로 재예약. "발표 중" 등. 카운트 유지
- **버튼**: 오버레이·알림 모두 스킵/미루기 버튼 제공

### 스마트 일시정지
- **자리 비움 자동 멈춤**: 유휴(예: 2분 무입력)면 타이머 정지, 복귀 시 남은 시간부터 재개. (자리 비운 동안 화면을 안 봤으니 눈도 쉰 것으로 간주)
- **전체화면 앱 미룸**: 브레이크 뜰 시점에 전체화면 앱(발표·영상)이면 짧게 미뤄 재시도

## 5. 상태 흐름 (BreakEngine 상태머신)

```
[작업중] ──타이머 만료──> [브레이크 예고] ──> [브레이크중] ──완료──> [작업중]
   ↑                          │                    │
   │                    전체화면 앱?           스킵/미루기 버튼
   │                    → 미룸(재예약)          → [작업중] 조기 복귀
   │
[일시정지] <──자리 비움 감지──┘   자리 복귀하면 남은 시간부터 재개
```

- 상태: `working` / `preBreak` / `onBreak` / `paused`
- 전이는 이벤트 기반: 타이머 만료, 유휴 감지/복귀, 전체화면 감지, 사용자 스킵/미루기, 브레이크 완료

---

## 6. 데이터 저장

- **전부 로컬. 클라우드·계정·로그인 없음.**
- **설정값** (주기, 개입 방식, 자동실행 등) → `UserDefaults`
- **통계** (오늘 브레이크 횟수·스킵 횟수) → `~/Library/Application Support/Blink/stats.json`
- 날짜가 바뀌면 오늘 요약 리셋 (히스토리 누적은 하지 않음 — YAGNI, 나중에 SQLite로 확장 가능)

---

## 7. 엣지 케이스 / 에러 처리

| 상황 | 처리 |
|---|---|
| 다중 모니터 | 오버레이를 모든 화면에 하나씩 |
| 브레이크 중 자리 비움 | 브레이크 완료로 처리 |
| JSON 저장 실패/손상 | 통계는 부가기능 → 조용히 무시하고 빈 상태로 시작 (앱 동작 안 막음) |
| 자동실행 권한 거부 | 설정 토글만 꺼진 채로 앱은 정상 동작 |
| 알림 권한 거부 | 알림 모드 대신 오버레이로 폴백 |

---

## 8. 테스트 전략

- **BreakEngine 단위 테스트가 핵심.** UI가 없으므로 **클럭을 주입 가능**하게 설계 → 실제 20분 안 기다리고 검증
  - "20분 경과 시 브레이크로 전이", "스킵 시 통계 +1", "유휴면 정지 후 복귀 시 재개" 등
- Scheduler·StatsStore도 순수 로직 → 단위 테스트
- UI(오버레이·메뉴바)는 수동 확인 — 자동화 비용 대비 효율 낮음

---

## 9. 타깃 / 스택

- **macOS 14 (Sonoma)+**, Swift 5.9+
- SwiftUI + 최소 AppKit (`NSPanel` 오버레이)
- 표준 프레임워크만: `SwiftUI`, `AppKit`, `UserNotifications`, `ServiceManagement`, `CoreGraphics`(idle 감지)
- **외부 라이브러리 없음**
- Xcode 프로젝트. 번들 ID(placeholder): `com.hangguma.blink`
